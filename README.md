# im-app

Página de entrada pública de la app I+M Mantención: solo el ícono (iPhone/Android), el nombre y el enlace a la app.
No contiene datos, claves ni código de la app (eso vive en el repositorio privado).

## proveedores/
Portal de proveedores instalable (mismo ícono). Enlace personal: `https://ing-mant.github.io/im-app/proveedores/#p=<token>` (el token va tras «#», no llega a GitHub). Muestra el portal de Google adentro; el PIN se pide igual en cada ingreso.
